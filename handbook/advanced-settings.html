Advanced settings

Advanced settings are not a menu on the scooter display. Change them using a computer or, if configured, through the cloud.

Finding a setting

The settings reference lists keys, values and defaults. Open Show advanced settings there. The display's Alarm menu contains the everyday options; individual trigger switches are advanced settings.

Only change settings you understand. Some affect the scooter's behavior and safety.

USB Update Mode

  1. With the scooter parked, open Update Mode, disconnect the internal dashboard USB cable from the MDB's Mini-B port and connect your computer there.
  2. Open settings.toml on the drive in a plain text editor. If the file is not there yet, you can create it.
  3. Add or change the entry in the appropriate TOML section. For example, to set alarm.trigger.motion:
[alarm.trigger]
motion = false

Change an existing entry instead of adding the entry or section twice. Some files represent the same value as "trigger.motion" under [alarm]. The file contains only explicitly saved values; missing keys use their defaults. Keep the existing entries: importing replaces the complete saved file. See file format and examples.

Save the file, safely eject the drive and leave Update Mode. The scooter imports the file. Reconnect and secure the internal dashboard cable afterward.

SSH and lsc

Connect your computer to the MDB in USB network mode. Log in over SSH and set the desired key:

ssh root@192.168.7.1
lsc get alarm.trigger.motion
lsc set alarm.trigger.motion false

This example turns off the motion trigger. Use the key and value from the settings reference. More commands are in the lsc guide. USB networking and Update Mode share the same port but cannot run at the same time; reconnect the dashboard cable afterward.

Browser interface with lsd

From Librescoot 1.4.0, including corresponding testing builds: connect your computer to the MDB in USB network mode and open http://192.168.7.1:8090. Turn on advanced mode in the top bar and open Settings. Search for a key and change it there. The dashboard must be on for USB networking to be available. See the lsd guide for details.

Sunshine

If your scooter is connected to Sunshine and online, its Settings page offers supported options under Advanced settings. The available options can differ from the local settings reference. See connectivity for setup.
