Web interface

Librescoot 1.4 preview

lsd runs on the scooter and provides settings, keycards, navigation destinations and routes, files, updates and log bundles in a browser. Local management needs no app, SIM card or account.

Connect over USB

Power the display on. Open the footwell, release the retaining screw on the MDB Mini-B port and disconnect the internal DBC USB cable. Connect the laptop to that port and open the web interface on the scooter. Reconnect and secure the internal cable when finished.

The USB network is normally active while the display runs; Update Mode replaces it with the drive. Service mode can hold the connection open.

Set up Sunshine

Sunshine is optional. Generate an installer credential in Sunshine Account settings. Paste its bootstrap token or online installer link into the Cloud page. The link must point to the configured Sunshine server. Whole shell commands and offline enrollment links do not belong in this field.

The web interface exchanges the credential for a configuration without executing an installer script. Accept new scooter claims in Sunshine to finish setup. The server is deployed independently of scooter firmware.

Access and diagnostics

With the default configuration, the interface also listens on an assigned wg0 IPv4 address, but not directly on the mobile-network interface. Access gives control over the scooter; advanced mode also exposes a shell. Only trusted WireGuard peers should reach the port. Token protection and a switch to disable the shell are available for other access models.

System provides log bundle downloads and service diagnostics. Updates shows both boards and their planned download size. A delta update can fall back to a full image, so the preview is not a hard data limit.
