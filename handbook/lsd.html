Web interface

Librescoot has a web interface, called lsd, that runs on the scooter. Connect a laptop to the scooter over USB and manage it in the browser: settings, keycards, navigation destinations, files, cloud connection, updates and logs, with a live view of everything the scooter reports.

Availability

The web interface ships in nightly builds since September 2026 and comes to the release channels with the next release. It needs nothing beyond a browser: no app, no SIM card, no account.

Connecting

  1. Turn the scooter on so the display is lit. The USB network is only up while the display is powered, unless service mode holds it up.
  2. Connect your laptop to the scooter's USB Mini-B port. Do not enter Update Mode; that replaces the network with the removable drive.
  3. The laptop receives an address from the scooter. Open http://192.168.7.1:8090 in a browser.

If the page does not load, check that the display is on and that no other USB mode is active. The interface is reachable on the USB cable only; it is not exposed over the mobile network.

Dashboard

The dashboard opens on the vehicle state and the batteries, then lists what the scooter reports: odometer, handlebar and seatbox, kickstand, keycards, mobile network, GPS position, the USB link, board versions and serial numbers, active faults and recent fault events. Everything updates live.

Below that are the commands. Unlock, lock, open seatbox, alarm, turn signals, horn, hibernate, timed sleep and reboot are there; anything that moves or powers the scooter down has to be held down for a moment rather than clicked, so a stray click does nothing. Service mode keeps the scooter awake with the USB link up and turns the alarm and the handlebar auto-lock off until you disable it again or reboot.

Settings

All settings the scooter knows, grouped by the component they belong to, with a description, the current value and the default. Switches for on and off, lists for choices, ranges checked as you type. Changes are collected and applied with one save; an empty field restores the default. Advanced settings are hidden until you tick Show advanced.

Keycards

The authorized cards and the master cards, and everything you can do at the reader: add a card by typing its UID or by tapping it, add another master by teach-in, remove a card. The last card held to the reader is shown with the verdict, and an unknown card can be authorized with one click. Start over removes every card; the next card tapped becomes the new master.

Navigation

Set the destination the display routes to, from coordinates or the scooter's own position, or pick one of the saved locations. The saved locations are the ones the display offers in its menu; add, rename, move and delete them here.

{% include news-screenshot.html src="/images/handbook/lsd-navigation.png" alt="The navigation page with the current destination, saved locations and a form for a new destination" caption="Navigation: destination and saved locations." %}

Files, cloud and updates

Files browses the scooter's data partition, with upload by drag and drop, download, and folder download as an archive.

Cloud connects the scooter to Sunshine: paste a bootstrap token from your Sunshine settings and the scooter registers itself and starts the connection. A configuration file for radio-gaga or uplink-service can also be installed by hand.

Updates shows each board's update state with progress and errors, lets you check for updates now, look up and switch the release channel, and install a downloaded .mender image or .delta patch. Files for the display are staged on the scooter and copied over when you install them.

Services and system

Services lists the Librescoot services on the scooter with their state, and lets you restart, stop or start them. System creates and downloads log bundles for support, shows the journal of any service, and lists the installed maps and the modem details.

{% include news-screenshot.html src="/images/handbook/lsd-system.png" alt="The system page with log bundles, maps, modem details and the journal viewer" caption="System: log bundles, maps, modem, journal." %}

A word on safety

The web interface can do everything the scooter can do, including unlocking it. It is only reachable over the USB cable, which is why it needs no login. Do not forward the port to any network you do not fully trust.
