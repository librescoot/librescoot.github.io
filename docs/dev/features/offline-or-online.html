Works Fully Offline

Ride and navigate offline. Reactivate or add a SIM for remote monitoring and automatic updates.

Fully offline

Core features work without an internet connection:

  • Navigation with local map tiles and routing engine
  • Alarm using the onboard acceleration sensor
  • Firmware updates over Bluetooth from your phone or via Update Mode (USB Mass Storage)
  • Dashboard with speedometer, battery, and all vehicle data

Online extras

With a SIM card in the 4G modem, you can use:

  • Cloud access: see your scooter's status, position, and battery level from anywhere, and control it remotely. Works with the Librescoot uplink or third-party cloud services
  • Over-the-air updates delivered automatically
  • Online map tiles without downloading offline packages
  • Remote routing via a Valhalla server

Bluetooth updates (preferred)

1.2+ For a routine update within the same release channel, transfer the delta artifact from stasis for unu (Android on Google Play, iOS on the App Store) over Bluetooth. This is the suggested path for most firmware updates.

Firmware for both MDB and DBC can be transferred. Use a .delta artifact matching the installed version when available; full .mender images take much longer.

After the transfer, the scooter prepares and installs the update. It waits until you lock it into stand-by before restarting to finish. It does not finalize the update while unlocked in parked or ready-to-drive.

The scooter must already run Librescoot 1.2 or newer. Getting to 1.2 for the first time still needs USB or a SIM.

USB updates

Use USB for maps and routing data, recovery, an offline channel change, or when no suitable Bluetooth delta is available. The scooter exposes a virtual drive in Update Mode. Copy files to the drive, eject it, and the scooter processes them automatically.
