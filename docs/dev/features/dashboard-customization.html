Dashboard Customization

Light and dark themes, configurable indicators and clock visibility.

Display themes

Choose a light or dark theme in the settings menu. Brightness adjusts to ambient light.

Configurable elements

Control what shows on your dashboard:

  • Clock visibility: show or hide the clock; the scooter has no RTC
  • Battery display mode: percentage or range
  • Status icons: toggle individual indicators on or off
  • Map rendering: vector or raster tiles

Milestone celebrations

The dashboard marks 10 km, every 100 km thereafter, and optional one-shot easter-egg numbers. Choose Milestones in Appearance: Off, Regular, or Regular + Easter eggs. Then choose Milestone presentation: Small notice, Banner, or Banner + confetti. Each level includes the brief notice at the crossing; banners appear when you park. Milestones are off by default.

lsc settings set dashboard.milestones.mode all
lsc settings set dashboard.milestones.presentation banner-and-confetti

Regular tickets count each completed 500 km with bronze stars. Five bronze stars become a silver star, five silver become gold, and five gold become a diamond; higher counts use a compact multiplier. The Easter Eggs menu's random demo still plays on demand when milestones are off.

Settings

Dashboard settings are accessible from the on-screen menu (double-tap left brake) or via the lsc CLI:

lsc settings list                          # See all settings
lsc settings set dashboard.map.type offline  # Switch to offline maps
lsc settings set dashboard.theme dark        # Dark theme
