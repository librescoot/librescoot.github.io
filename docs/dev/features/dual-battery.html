Dual Battery Support

Use both battery slots for more range.

What it does

Librescoot supports running two batteries simultaneously. The battery service monitors both via NFC and manages them together. Both batteries discharge in parallel, giving you roughly double the range of a single battery.

Hardware mod required

The stock scooter has one wired battery slot. Open the scooter and add a connector and cable to the second bay.

Software side

battery-service detects the second battery automatically. Enable dual-battery mode with lsc settings set scooter.dual-battery true to use it; otherwise it stays idle.
