Settings Reference

This reference lists the settings available in current development builds. For everyday changes, use the dashboard or the settings controls described in the Handbook. Settings can also be inspected or changed with lsc.

Settings marked user-visible are listed below. All other settings are in the collapsed Advanced settings section. Service Mode temporarily overrides several keys and stays active across reboots.
