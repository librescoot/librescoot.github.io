Service Mode

Service Mode keeps the scooter accessible for maintenance. It prevents automatic standby and idle hibernation, disables the alarm, keeps the USB link up, releases the handlebar latch and shows the debug screen. Use it only while you are working on the scooter.

Before you leave: Turn Service Mode off explicitly. It remains active across reboots; restarting the scooter does not restore the alarm or automatic handlebar re-lock. Do not leave the scooter unattended in Service Mode.

Enable and disable

  1. From the dashboard menu, choose Settings → System → Service Mode to turn it on. See the menu reference.
  2. On the debug screen, hold the left brake for three seconds to leave Service Mode. You can also use Disable Service Mode at the top of the dashboard menu when the menu is available.

You can also manage it with lsc on the MDB:

lsc service-mode status
lsc service-mode on
lsc service-mode off

Check the status after turning it off, especially before leaving the scooter unattended.

What changes

AreaWhile Service Mode is active
PowerAutomatic standby and inactivity hibernation are disabled; the power manager stays in run mode.
SecurityThe alarm is disabled. The handlebar latch is released and automatic handlebar re-locking is suppressed.
ConnectivityThe USB network link stays on.
DisplayThe debug screen is selected.

Service Mode does not itself command a vehicle-state unlock. Vehicle lock and unlock remain separate actions. The overridden settings are restored when you turn Service Mode off; ordinary settings edits to those fields take effect after you leave the mode.

Technical details

The settings-service applies a persistent overlay rather than saving the forced values as your preferences. It sets scooter.auto-standby-seconds=0, pm.hibernation-timer=0, pm.default-state=run, alarm.enabled=false, scooter.usb0-policy=always-on, dashboard.mode=debug and scooter.handlebar-unlocked=true. For individual keys, see the settings reference.
