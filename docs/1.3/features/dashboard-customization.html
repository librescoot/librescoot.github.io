Dashboard Customization

Light and dark mode, configurable display, and a clock that synchronizes from GPS when available.

Display themes

Choose a light or dark theme in the settings menu. Brightness adjusts to ambient light.

Configurable elements

Control what shows on your dashboard:

  • Clock: show or hide the time; GPS sets it once a fix is available
  • Battery display mode: percentage or range
  • Status icons: toggle individual indicators on or off
  • Map rendering: vector or raster tiles

The scooter has no battery-backed real-time clock (RTC) to keep time while powered off. The dashboard sets its clock from GPS once it gets a fix, including when riding offline.

Milestone celebrations

When enabled, the dashboard marks every 500 km. It can also mark selected easter-egg numbers. A short notice appears at the milestone, followed by a banner and confetti when you next park. The feature is off by default; enable Milestone Celebrations in the Appearance settings, or use:

lsc settings set dashboard.milestone-celebrations true

Settings

Dashboard settings are accessible from the on-screen menu (double-tap left brake) or via the lsc CLI:

lsc settings list                          # See all settings
lsc settings set dashboard.map.type offline  # Switch to offline maps
lsc settings set dashboard.theme dark        # Dark theme
