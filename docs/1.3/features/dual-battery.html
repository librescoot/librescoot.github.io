Dual Battery Support

Use both battery slots for more range.

What it does

Dual-battery mode lets the scooter use the capacity of two connected main batteries. It requires both the wiring modification and the battery-mode setting below. Range depends on the packs' charge and condition, as well as riding conditions.

Hardware mod required

The scooter already has front and rear battery slots, but only the front one is wired in the stock configuration. The rear slot needs a battery connector and the dual-battery wiring before it can supply power.

Software side

After completing the wiring, choose Dual Battery under Settings > Vehicle > Battery Mode, or run lsc settings set scooter.dual-battery true. The setting enables the rear pack for use; inserting a second battery alone does not enable this mode. With Single Battery selected, the rear pack does not supply drive power.
