Dashboard Menu Reference

This page shows the dashboard menu in Librescoot 1.3.x. Road Name and Speed Limit were added in 1.3.1.

While parked on the speedometer or map, pull the left brake twice quickly to open the menu. Follow the on-screen controls to move, select or go back; selecting a setting with choices moves to the next choice.

Main menu

  • Disable Service Mode
    • Turns off Service Mode. Shown only while it is on.
  • Activate Hop-on
    • Activates hop-on mode. Shown only after you set a combo under Settings → Vehicle → Hop On / Hop Off….
  • Navigation
    • Plan a route. Shown when a map can be displayed and routing is available, either on the scooter or online with a connected modem.
    • Enter Address…
      • Choose an address to navigate to.
    • Recent Destinations
      • Choose from up to ten places you have navigated to. Shown when you have recent destinations.
      • Each destination — shown by its name or coordinates.
        • Start Navigation — navigate there.
        • Save Location — add it to your saved locations.
        • Delete Location — remove it from recent destinations.
    • Saved Locations
      • Save Current Location — save your current position.
      • Each saved location — shown by its name or coordinates.
        • Start Navigation — navigate there.
        • Delete Location — remove it from your saved locations.
    • Stop Navigation
      • Clears the route. Shown while you have a route, even if you have arrived or it is recalculating.
    • Maps & Routing…
      • Open the map and routing setup screen.
  • Set up Navigation
    • Opens routing setup. Shown when routing is not ready.
  • Set up Map Mode
    • Opens map setup. Shown in cluster view when offline maps are missing and online maps are not selected.
  • Switch to Cluster View
    • Opens the speedometer view. Shown when you are on another screen.
  • Switch to Map View
    • Opens the map. Shown when you are not already on it and offline maps are available or online maps are selected.
  • Lock Scooter
    • Locks the scooter. Shown while parked.
  • Toggle Hazard Lights
    • Turns both blinkers on, or turns them off if they are already on.
  • Faults
    • Opens the fault list. Shown only when faults are active, with their count beside the title.
  • Settings
    • Appearance, Vehicle, Map & Navigation and System are listed below.
  • Info
    • The number of active faults appears next to Info when there are any.
    • Components — view component information.
    • Connectivity — view connection information.
    • Batteries — view battery information.
    • Maps — view installed map information.
    • Faults — view faults; the count appears when any are active.
    • About & Licenses — view software information and licenses.
  • Exit Menu
    • Close the menu.

Settings

  • Appearance
    • Theme
      • Automatic — change between light and dark automatically.
      • Dark — keep the dark theme.
      • Light — keep the light theme.
    • Backlight
      • Automatic — adjust brightness to ambient light.
      • Low — keep the backlight dim.
      • Medium — use medium brightness.
      • High — use high brightness.
    • Power Display
      • Power (kW) — show motor power in kilowatts.
      • Current (A) — show current in amperes.
    • Blinkers
      • Blinker Style
        • Icon (default) — show a blinker icon.
        • Fullscreen Arrow — show a larger on-screen arrow.
      • DBC Blinker LED
        • Off — do not use the dashboard's physical blinker light.
        • On — flash the dashboard's physical blinker light.
    • Status Bar
      • Battery Display
        • Percentage — show remaining battery charge as a percentage.
        • Range (km) — show estimated riding range.
        • Icons Only — show battery icons without a number.
      • CBB Battery
        • Always — always show the backup battery indicator.
        • When Low — show it when the backup battery is low.
        • Never — hide it.
      • 12V Battery
        • Always — always show the auxiliary battery indicator.
        • When Low — show it when the auxiliary battery is low.
        • Never — hide it.
      • GPS Icon
        • Always — keep the icon visible.
        • Active or Error — show it when GPS is active or has a problem.
        • Error Only — show it only when there is a problem.
        • Never — hide it.
      • Bluetooth Icon
        • Always — keep the icon visible.
        • Active or Error — show it when Bluetooth is active or has a problem.
        • Error Only — show it only when there is a problem.
        • Never — hide it.
      • Cloud Icon
        • Always — keep the icon visible.
        • Active or Error — show it when the cloud connection is active or has a problem.
        • Error Only — show it only when there is a problem.
        • Never — hide it.
      • Internet Icon
        • Always — keep the icon visible.
        • Active or Error — show it when internet is active or has a problem.
        • Error Only — show it only when there is a problem.
        • Never — hide it.
      • Clock
        • Time — show the time.
        • Date + Time — show both together.
        • Alternating — alternate between date and time.
        • Never — hide the clock.
      • Temperature
        • Always — always show temperature.
        • Warning Only — show it only when a temperature warning needs attention.
        • Never — hide it.
    • Milestone Celebrations
      • Off — no odometer celebrations.
      • On — show celebrations at distance milestones.
  • Vehicle
    • Hop On / Hop Off…
      • Set up hop-on mode. Opens an introduction if you have no combo yet; otherwise offers these choices:
      • Set new combo… — record a new control sequence.
      • Disable hop-on — remove the combo.
    • Alarm
      • Enable on Lock
        • Off — disable the alarm.
        • On — enable it.
      • Honk on Trigger
        • Off — no horn during an alarm.
        • On — sound the horn during an alarm.
      • Duration
        • Short (10s) — sound for 10 seconds.
        • Medium (20s) — sound for 20 seconds.
        • Long (30s) — sound for 30 seconds.
    • Battery Mode
      • Single Battery — one battery is connected.
      • Dual Battery — two batteries are connected; use only with dual-battery wiring.
    • Horn While Seatbox Open
      • Off — prevent accidental honking when the open seatbox lid presses the horn button.
      • On — allow the horn while the seatbox is open.
  • Map & Navigation
    • Map View
      • 3D — angled map view.
      • 2D — flat map view from above.
    • Orientation — choose which way the map points. Shown in 2D view only.
      • Heading — rotate the map to face your direction of travel.
      • North — keep north at the top.
    • Road Name — available from 1.3.1.
      • Always — show the road name when available.
      • Map Only — show it on the map, not the speedometer.
      • When Navigating — show it during navigation.
      • Never — hide it.
    • Speed Limit — available from 1.3.1.
      • Always — show the speed limit when available.
      • Map Only — show it on the map, not the speedometer.
      • When Navigating — show it during navigation.
      • Over Limit — show it when you exceed the limit.
      • Never — hide it.
    • Route
      • Fastest — favor the shortest travel time.
      • Shortest — favor the shortest distance.
    • Avoid Cobblestone — choose how strongly routes should avoid cobblestones. Shown for Fastest routes with on-device routing; not offered for Shortest routes or the public online routing service.
      • Off — do not avoid cobblestones.
      • Low — a slight preference for smoother roads.
      • Medium — a stronger preference for smoother roads.
      • High — avoid cobblestones more strongly.
    • Map Updates
      • Off — do not check for map updates automatically.
      • Notify — check for updates and let you know when one is available.
      • Download — check and download updates automatically.
    • Check for Updates
      • Check for new maps now. Shown when maps are installed; checking requires an internet connection. The last check time appears next to the entry.
    • Map Type
      • Online — load map tiles over the internet.
      • Offline — use maps stored on the scooter.
    • Navigation Routing
      • Online — get routes from an online routing service.
      • Offline — calculate routes on the scooter.
  • System
    • Language
      • English — use English menus.
      • Deutsch — use German menus.
    • Update Mode…
      • Open the instructions for transferring files to the scooter over USB.
    • Service Mode
      • Turns on Service Mode. Shown only while it is off.
    • Clear Bluetooth Connections…
      • Opens a confirmation to remove every paired phone. Shown only while parked. Each phone must be paired again afterwards.
      • Clear All Bluetooth Connections — remove all paired phones.
    • Updates
      • Check Frequency
        • Off — no scheduled checks; you can still check manually.
        • 6h — check every six hours.
        • 12h — check every twelve hours.
        • 24h — check daily.
        • 3d — check every three days.
        • 7d — check weekly.
        • If the scooter's two computers disagree, the entry says “Diverged”. An interval set elsewhere can also appear as a value.
      • Check for Updates Now
        • Start a check now. The last check time appears next to the entry.
      • Change Update Type
        • Delta — download only the changes needed for the update.
        • Full — download the complete software image; this uses much more data.
        • The current type appears next to the entry. “Diverged” means the scooter's two computers are set differently; choosing either option sets both.
      • Switch Release Channel
        • Stable — regular releases.
        • Testing — releases being tested before stable.
        • Nightly — frequent development builds.
        • The current channel appears next to the entry. “Diverged” means the two computers are set differently. Changing channels may download a full image.
    • Capture Logs
      • Collect diagnostic logs; a notification reports when it finishes.
