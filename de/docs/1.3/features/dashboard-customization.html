Dashboard anpassen

Light- und Dark-Mode, konfigurierbare Anzeige und eine Uhr, die sich bei GPS-Empfang automatisch stellt.

Display-Themes

Wähle ein helles oder dunkles Design im Einstellungsmenü. Die Helligkeit passt sich dem Umgebungslicht an.

Konfigurierbare Elemente

Was auf deinem Dashboard erscheint, bestimmst du:

  • Uhr: Uhrzeit ein- oder ausblenden; GPS stellt sie bei Empfang automatisch
  • Akkuanzeige: Prozent oder Reichweite
  • Status-Icons: einzelne Indikatoren gezielt ein- oder ausschalten
  • Kartendarstellung: Vektor- oder Raster-Kacheln

Der Roller hat keine batteriegepufferte Echtzeituhr (RTC, Real-Time Clock), die im ausgeschalteten Zustand die Uhrzeit weiterführt. Das Dashboard stellt die Uhr bei GPS-Empfang, auch ohne Internetverbindung.

Meilensteine feiern

Bei aktivierter Funktion markiert das Dashboard jede 500-km-Marke und auf Wunsch besondere Easter-Egg-Zahlen. Beim Erreichen erscheint ein kurzer Hinweis, beim nächsten Parken ein Banner mit Konfetti. Die Funktion ist standardmäßig aus. Aktiviere Meilensteine feiern in den Darstellungseinstellungen oder mit:

lsc settings set dashboard.milestone-celebrations true

Einstellungen

Dashboard-Einstellungen erreichst du über das Bildschirmmenü (doppelt auf die linke Bremse tippen) oder per lsc-CLI:

lsc settings list                          # Alle Einstellungen anzeigen
lsc settings set dashboard.map.type offline  # Auf Offline-Karten umschalten
lsc settings set dashboard.theme dark        # Dark-Theme
