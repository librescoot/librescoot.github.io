Roller-Alarmanlage

Die eingebaute Alarmanlage erkennt Bewegung und Manipulationsversuche am geparkten Roller. Den Alltag – Scharfstellen, das Menü am Display und was bei einer Auslösung passiert – beschreibt die Fahren-Seite im Handbuch; diese Seite dokumentiert das vollständige Verhalten und die Konfiguration.

Wie sie funktioniert

Ist Bei Sperre aktivieren eingeschaltet, wird die Alarmanlage scharf, nachdem der Roller in den Standby gewechselt ist. Beim Aufsperren wird sie entschärft.

Eine scharfe Alarmanlage kann durch Folgendes ausgelöst werden:

  • Bewegung — standardmäßig aktiviert
  • Tasten — Betätigung der linken oder rechten Bremse, der Hupe oder der Sitzbanktaste; als gemeinsame Gruppe standardmäßig aktiviert
  • Sitzbank — Öffnen der Sitzbank ohne vorherige berechtigte Entriegelung
  • Lenker — wenn das Lenkschloss auf „entriegelt“ wechselt oder der Lenker die Parkposition verlässt; optional und standardmäßig deaktiviert

Um Fehlalarme beim Abstellen zu vermeiden, werden Lenkerauslöser in den ersten 90 Sekunden nach dem Scharfschalten ignoriert. Danach muss eine abweichende Lenkerposition eine Sekunde lang bestehen, bevor sie Alarm auslöst.

Zur Diagnose speichert die Alarmanlage den Auslöser und den Zeitpunkt des letzten Alarms.

Einstellungen am Dashboard

Öffne Einstellungen → Fahrzeug → Alarm. Dort findest du:

  • Bei Sperre aktivieren — schaltet die Alarmanlage beim Wechsel in den Standby scharf
  • Hupen bei Auslösung — verwendet bei einem Alarm die Hupe
  • Dauer — 10, 20 oder 30 Sekunden

Die Schalter für die einzelnen Auslöser sind erweiterte Einstellungen und erscheinen nicht als eigene Zeilen im Dashboard.

Fortgeschritten: Konfiguration über die CLI

Mit den aktuellen lsc-Befehlen kannst du die Alarmanlage prüfen und konfigurieren:

lsc alarm status       # Alarmstatus und Einstellungen anzeigen
lsc alarm arm          # Alarm aktivieren; wird im Standby scharf
lsc alarm disarm       # Alarm deaktivieren und entschärfen

lsc settings set alarm.enabled true
lsc settings set alarm.honk true
lsc settings set alarm.duration 20

Die erweiterten Auslöserschalter akzeptieren true oder false:

lsc settings set alarm.trigger.motion true
lsc settings set alarm.trigger.motion false
lsc settings set alarm.trigger.buttons true
lsc settings set alarm.trigger.buttons false
lsc settings set alarm.seatbox-trigger true
lsc settings set alarm.seatbox-trigger false
lsc settings set alarm.trigger.handlebar true
lsc settings set alarm.trigger.handlebar false
