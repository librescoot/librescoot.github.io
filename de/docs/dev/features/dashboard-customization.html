Dashboard anpassen

Helles und dunkles Design, anpassbare Anzeigen und einstellbare Uhranzeige.

Display-Themes

Wähle ein helles oder dunkles Design im Einstellungsmenü. Die Helligkeit passt sich dem Umgebungslicht an.

Konfigurierbare Elemente

Was auf deinem Dashboard erscheint, bestimmst du:

  • Uhranzeige: Uhrzeit ein- oder ausblenden; GPS stellt sie bei Empfang automatisch
  • Akkuanzeige: Prozent oder Reichweite
  • Status-Icons: einzelne Indikatoren gezielt ein- oder ausschalten
  • Kartendarstellung: Vektor- oder Raster-Kacheln

Der Roller hat keine batteriegepufferte Echtzeituhr (RTC, Real-Time Clock), die im ausgeschalteten Zustand die Uhrzeit weiterführt. Das Dashboard stellt die Uhr bei GPS-Empfang, auch ohne Internetverbindung.

Meilensteine feiern

Bei aktivierter Funktion markiert das Dashboard 10 km und danach jede 100-km-Marke. Beim Erreichen erscheint ein kurzer Hinweis; auf Wunsch folgen beim nächsten Parken Banner und Konfetti.

Unter Meilensteine in den Darstellungseinstellungen wählst du Aus, Regulär oder Regulär + Easter Eggs. Meilenstein-Darstellung bietet Kleiner Hinweis, Banner oder Banner + Konfetti. Meilensteine sind standardmäßig aus.

lsc settings set dashboard.milestones.mode all
lsc settings set dashboard.milestones.presentation banner-and-confetti

Einstellungen

Ändere die Dashboard-Einstellungen im Bildschirmmenü (zweimal kurz die linke Bremse ziehen), auf der Einstellungsseite von lsd oder mit lsc:

lsc settings list                          # Alle Einstellungen anzeigen
lsc settings set dashboard.map.type offline  # Auf Offline-Karten umschalten
lsc settings set dashboard.theme dark        # Dark-Theme
