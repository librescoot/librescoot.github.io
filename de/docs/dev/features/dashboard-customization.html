Dashboard anpassen

Light- und Dark-Mode, konfigurierbare Anzeige und endlich ein Weg, die kaputte Uhr zu reparieren oder auszublenden.

Display-Themes

Das Dashboard unterstützt Light- und Dark-Theme, umschaltbar im Einstellungsmenü. Die Helligkeit passt sich automatisch an den Umgebungslichtsensor an.

Konfigurierbare Elemente

Was auf deinem Dashboard erscheint, bestimmst du:

  • Uhr ein-/ausblenden: blende die Uhr aus, wenn sie die falsche Zeit anzeigt (das passiert, wenn er offline ist, weil keine RTC verbaut ist)
  • Akkuanzeige: Prozent oder Reichweite
  • Status-Icons: einzelne Indikatoren gezielt ein- oder ausschalten
  • Kartendarstellung: Vektor- oder Raster-Kacheln

Meilensteine feiern

Das Dashboard markiert 10 km, danach jede 100-km-Marke und optional einmalige Easter-Egg-Zahlen. Unter Meilensteine im Darstellungsmenü wählst du Aus, Regulär oder Regulär + Easter Eggs. Unter Meilenstein-Darstellung wählst du Kleiner Hinweis, Banner oder Banner + Konfetti. Jede Darstellungsstufe zeigt beim Erreichen einen kurzen Hinweis; Banner erscheinen beim nächsten Parken. Standardmäßig sind Meilensteine ausgeschaltet.

lsc settings set dashboard.milestones.mode all
lsc settings set dashboard.milestones.presentation banner-and-confetti

Reguläre Tickets zählen je 500 gefahrene Kilometer mit Bronzesternen. Fünf Bronzesterne werden zu einem Silberstern, fünf Silbersterne zu einem Goldstern und fünf Goldsterne zu einem Diamanten; höhere Zahlen erscheinen als kompakter Multiplikator. Die Zufalls-Demo im Easter-Egg-Menü funktioniert auch bei ausgeschalteten Meilensteinen.

Einstellungen

Dashboard-Einstellungen erreichst du über das Bildschirmmenü (doppelt auf die linke Bremse tippen) oder per lsc-CLI:

lsc settings list                          # Alle Einstellungen anzeigen
lsc settings set dashboard.map.type offline  # Auf Offline-Karten umschalten
lsc settings set dashboard.theme dark        # Dark-Theme
