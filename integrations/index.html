Integrations

Apps and services for phones, Home Assistant, and navigation. They connect to the scooter either directly over Bluetooth or through an online service.

Bluetooth

A phone or ESP32-S3 talks directly to the scooter when it is nearby. No cellular plan or online account required.

iOS & Android App stores

The ready-to-use everyday app. Control the scooter, check its status, install updates, and send destinations to the dashboard – all directly over Bluetooth.

  • Firmware updates from Librescoot 1.2

Home Assistant Librescoot 1.4+

Librescoot-BLE-Component

dtill/librescoot-homeassistantby dtill

Home Assistant without a cellular plan. An ESP32-S3 stays near the scooter and connects it over Bluetooth – even while it hibernates.

  • Pair using the code on the dashboard
  • Firmware updates through Home Assistant
  • Presence, readings, and alarm

Needs: ESP32-S3 with librescoot-esphome

Install via HACS ESPHome Source
02

Sunshine

Sunshine makes the scooter reachable over the internet. Both apps below need an online scooter and a Sunshine account.

For a self-hosted Librescoot connection, there is also uplink-service on the scooter and uplink-server with a web UI and REST API on the server.

Home Assistant HACS

Sunshine Scooter

librescoot/sunshine-homeassistantby Librescoot

Your scooter in your smart home. Location, vehicle data, and controls arrive in Home Assistant through your Sunshine account.

  • Location and odometer
  • Batteries, range, motor, and firmware
  • Lock, alarm, blinkers, horn, and locate
  • Second, AUX, and CBB batteries where present

Librescoot Navigation

ligustah/lsnavby ligustah

Share a destination, then ride there. The Android app receives a shared maps link and sends the destination to the scooter through Sunshine.

  • Links from Google Maps and Apple Maps
  • Set or clear the destination on the scooter
  • Sunshine URL and API token in the app

There is no ready-made build yet; the app is built from source.
