stasis for unu

reunu/unustasisby freal

The app for day-to-day use. Control the scooter, check its status, install updates, and send destinations to the dashboard.

  • Lock, seatbox, blinkers, and horn
  • Batteries, range, odometer, and status
  • Firmware updates from Librescoot 1.2

Home Assistant Librescoot 1.4+

Librescoot-BLE-Component

dtill/librescoot-homeassistantby dtill

Home Assistant without a cellular plan. An ESP32-S3 within range connects Home Assistant to the scooter, even while the scooter is hibernating.

  • Pair using the code shown on the dashboard
  • Firmware updates through Home Assistant
  • Presence, readings, and alarm

Requires: ESP32-S3 with librescoot-esphome

Install via HACS ESPHome Source

Sunshine

Sunshine requires internet access on the scooter and a Sunshine account.

To host the cloud yourself, set up uplink-server on your own server and configure uplink-service on the scooter.

Web app & API Open source

Sunshine

rescoot/sunshineby rescoot

The new cloud platform for unu scooters. Sunshine displays telemetry and trips in the browser and sends commands to the scooter. Sunshine provides its own telemetry client, radio-gaga, which is bundled with Librescoot, and also supports uplink-service.

  • Live location and vehicle status
  • Trips, statistics, and history
  • Lock, seatbox, blinkers, and horn
  • REST API and MCP server
Open Sunshine Source
Home Assistant HACS

Sunshine Scooter

librescoot/sunshine-homeassistantby Librescoot

Your scooter in your smart home. The integration sends location and vehicle data to Home Assistant and exposes the scooter controls there.

  • Location and odometer
  • Batteries, range, motor, and firmware
  • Lock, alarm, blinkers, horn, and locate
  • Second, AUX, and CBB batteries where present

Librescoot Navigation

ligustah/lsnavby ligustah

Share a destination, then ride there. Use the Android share sheet to send a destination from Google Maps or Apple Maps to the scooter through Sunshine.

  • Links from Google Maps and Apple Maps
  • Set or clear the destination on the scooter
  • Sunshine URL and API token in the app

No ready-made builds are available yet; the app must be built from source.
