Screenshots

Every picture here was taken on a scooter running Librescoot. Click one to enlarge it, or follow the link under it to the page that explains what it shows.

Riding and navigation

On the move the cluster shows the speedometer and the trip data, and an active route hands the middle of the screen to the map. Which clock the status bar carries — the time, the time with the date beside it, or alternating between the two — is a display setting.

{% include news-screenshot.html src="/images/hero/cluster-driving-en.png" alt="Light dashboard while riding at 28 km/h" caption="Riding at 28 km/h: speed, charge, estimated range and the time left at the current pace." %}

The trip data and the energy gauge are described in Riding, and what you can rearrange is in Dashboard customization.

{% include news-screenshot.html src="/images/hero/map-date-time-en.png" alt="Light navigation map with the date-and-time clock style" caption="The map with the clock in “Date + Time” mode." %}

The clock modes are described in Display: “Date + Time” puts the day beside the time, “Alternating” swaps between the two.

{% include news-screenshot.html src="/images/hero/map-2d-heading-en.png" alt="Heading-up 2D navigation with an active route" caption="The 2D map turned into the direction of travel, with an active route." %}

Navigation covers starting a route, Offline navigation the data behind the map.

{% include news-screenshot.html src="/images/hero/map-date-alternate-en.png" alt="Navigation with the alternating clock showing 1 May" caption="The alternating clock, here showing the day with the month." %}

The \"Alternating\" mode swaps between the time and the day with month every few seconds; see Display.

{% include news-screenshot.html src="/images/hero/map-roundabout-en.png" alt="Roundabout guidance on an active route" caption="Roundabout guidance on an active route." %}

Manoeuvre guidance is part of Navigation.

Instrument cluster states

The cluster renders in a light and a dark theme, and the telltale card carries whatever the vehicle is reporting: park mode, hazards, the parking brake, or a fault that needs attention. The display chapter walks through the areas of the screen, vehicle states through the modes behind them.

What each warning means, and what to do about it, is in Troubleshooting.

Settings, updates and over-the-air installs

Settings and updates are handled on the scooter, so neither needs a phone. Channels, check frequency and the update type live in the Updates menu; a running install reports itself in the status bar. Updates is the reader-facing guide, Update Mode and the services reference the technical background.

{% include news-screenshot.html src="/images/news/settings-root.png" alt="The Settings menu grouped by topic" caption="Settings are grouped by topic instead of one long list." %}
{% include news-screenshot.html src="/images/news/settings-map-navigation.png" alt="Map and Navigation settings menu with map view, route, and update choices" caption="Map view, route choice and map updates are configured in one menu." %}

See Navigation for what the choices do on the road.

{% include news-screenshot.html src="/images/news/updates-menu.png" alt="The Updates menu on the scooter" caption="Check frequency, manual checks, update type and release channel in one place." %}

Updates explains the channels and what a channel switch costs.

Maps and routing

Map tiles and routing data live on the scooter, so navigation keeps working without a mobile connection. Both have a day and a night rendering that follow the display theme.

{% include news-screenshot.html src="/images/handbook/map-nav-day.png" alt="Day map view with an active route on the scooter display" caption="Turn-by-turn guidance in day view." %}
{% include news-screenshot.html src="/images/handbook/map-route-light-en.png" alt="Map view in day mode with a turn-by-turn instruction, street name plate, and speed-limit sign" caption="Day view, with the street name plate and the speed-limit sign beneath the instruction." %}
{% include news-screenshot.html src="/images/handbook/map-route-dark-en.png" alt="The same map view in night mode with a dark background" caption="The same scene in night view." %}

Offline navigation explains how maps and routing data get onto the scooter, and Navigation how you start a route.
